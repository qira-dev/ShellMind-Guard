# Security Policy

## Reporting a Vulnerability
Please report suspected security vulnerabilities in ShellMind Guard via **GitHub Private Vulnerability Reporting** (`Security` tab -> `Report a vulnerability` on `https://github.com/qira-dev/ShellMind-Guard`) rather than opening a public issue.

## Response SLAs
- **Initial Triage & Acknowledgement:** within **48 hours**
- **Severity Assessment & Fix Target (Critical / High):** within **14 days**
- **Coordinated Disclosure:** credit given upon release of a patched version (`SHA256SUMS.txt` + GitHub Artifact Attestation).

## Supported Versions
| Version | Supported |
|---|---|
| `1.6.x` | Yes |
| `1.5.x` | Security fixes only |
| `< 1.5.0` | No |
